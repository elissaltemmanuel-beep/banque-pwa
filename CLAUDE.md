# Règles pour ce dépôt

- **Publier directement sur `main`.** Après chaque modification validée, la commiter, la fusionner dans `main` et pousser `main` (l'application installée se met à jour depuis `main`). Ne pas laisser le travail sur une branche seule. Pas de pull request sauf demande explicite.
- Changer `BUILD` dans `config.js` (et le commentaire de build en tête de `sw.js`) à chaque publication, pour que la version affichée dans Plus > Version de l'application prouve que la mise à jour est arrivée.
- Répondre en français.
